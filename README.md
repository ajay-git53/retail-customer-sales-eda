# Retail Customer Sales EDA

Exploratory data analysis of a retail customer sales dataset, including data cleaning, descriptive statistics, visualisations, outlier analysis, and business insights.

## Project Structure

- `data/` - Original retail customer sales dataset
- `notebooks/EDA_Analysis.ipynb` - EDA notebook
- `outputs/` - Cleaned data and generated charts
- `reports/Insights_Report.docx` - Project insights report
- `2026M01410010_Ajay_Pratap_Singh_Chauhan_Retail_Customer_Sales_EDA_Project_Synopsis.docx` - Project synopsis

## Analysis Highlights

- Dataset structure, types, missing values, and duplicates
- Numerical and categorical variable summaries
- Histograms and box plots
- Sales analysis by category, region, segment, and payment method
- Outlier detection
- Derived features and cleaned dataset export

## Run the Notebook

Install Python dependencies such as pandas, numpy, matplotlib, seaborn, and openpyxl, then open:

```bash
jupyter notebook notebooks/EDA_Analysis.ipynb
```
